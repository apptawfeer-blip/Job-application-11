# صيغة طابور الواتساب (لإضافة Chrome)

كل تشغيل لأمر **"تقديم واتس"** ينتج ملفين في `output/whatsapp/`:

- `queue_<YYYY-MM-DD>_<run>.json`: الملف الأساسي للإضافة
- `queue_<YYYY-MM-DD>_<run>.csv`: نفس البيانات للفتح في Excel (UTF-8 BOM)

## بنية JSON

```json
{
  "date": "2026-11-26",
  "run": "2026-11-26_1015_whatsapp",
  "items": [
    {
      "id": 1,
      "name": "اسم الجهة",
      "country": "Jordan",
      "row": 892,
      "phone": "962791234567",
      "wa_link": "https://wa.me/962791234567",
      "text": "نص الرسالة الجاهز (2–4 أسطر)",
      "lang": "AR",
      "cv": "Full",
      "type": "مركز تربية خاصة",
      "cv_path": "cv/Amer_AlSaaideh_CV_Arabic.pdf",
      "cv_send_name": "Amer_AlSaaideh_CV_Arabic.pdf",
      "suggested_time": "09:00",
      "status": "pending_approval",
      "sent_at": ""
    }
  ]
}
```

| الحقل | المعنى |
|---|---|
| `phone` | الرقم بصيغة دولية، أرقام فقط بدون `+` |
| `wa_link` | رابط فتح المحادثة مباشرة |
| `text` | النص كما سيُرسل، لا يُعدَّل آلياً |
| `cv_path` | مسار ملف السيرة داخل المستودع (قد يكون نسخة `_S` للمدارس والجامعات) |
| `cv_send_name` | **الاسم الذي يجب أن يظهر للجهة** عند إرفاق الملف. لا يظهر الرمز `_S` أبداً |
| `suggested_time` | وقت مقترح بفاصل عشوائي 3–6 دقائق بين الرسائل (سياسة منع الحظر) |
| `status` | `pending_approval` (جهّزها Claude، **ممنوع إرسالها**) ← `ready` (اعتمدها المستخدم فقط) ← `sent` (أو `skipped` / `failed`) |
| `sent_at` | وقت الإرسال الفعلي ISO-8601 |

## ما تفعله الإضافة

1. تقرأ أحدث `queue_*.json` وتعرض الرسائل بالترتيب.
2. لكل رسالة: تفتح `wa_link`، تضع `text`، تجهّز المرفق `cv_path` باسم `cv_send_name`، ثم **المستخدم يقرأ ويضغط إرسال بنفسه**.
3. تحترم `suggested_time` (أو على الأقل فاصل 3 دقائق بين رسالتين).
4. بعد الإرسال تكتب النتيجة بإحدى طريقتين:
   - تعديل `status` إلى `sent` و`sent_at` داخل ملف الطابور نفسه، **أو**
   - كتابة ملف `output/whatsapp/sent_<YYYY-MM-DD>.json` بالشكل:
     ```json
     [{"run": "2026-11-26_1015_whatsapp", "id": 1, "phone": "962791234567", "status": "sent", "sent_at": "2026-11-26T09:04:00+03:00"}]
     ```
5. بعدها يشغّل الـ agent `python3 scripts/pipeline.py sync-wa` (ضمن "تقديم حالة" أو التذكير الصباحي)، فيسجّل المرسَل في `applications_log.xlsx` ويحدّث ملف الدولة واللوحة.

## حدود الأمان
- لا ترسل الإضافة أكثر من الحصة اليومية في `config/sending_policy.json` (أسبوع 1: 10، أسبوع 2: 15، ثم 20، سقف 25).
- إذا ظهر أي تحذير أو تقييد من واتساب ← توقف فوراً وأخبر الـ agent (يُسجَّل في `issues_log.xlsx`).

## قاعدة الموافقة (بطلب المستخدم 26/11 – إلزامية)
- كل رسالة يجهّزها Claude تُكتب بالحالة `pending_approval`، و**الإضافة لا ترسل إلا الحالة `ready`**.
- `ready` تعني أن المستخدم وافق على هذه الرسالة بعينها (أو قال صراحة "وافقت على الطابور كله"). Claude لا يضع `ready` إلا بعد هذه الموافقة الصريحة في المحادثة، ولا يرسل واتساب أبداً بنفسه.
- طابور الواتساب لا يُجهَّز إلا عندما يطلبه المستخدم ("تقديم واتس N")، لا في أي مهمة مجدولة.
